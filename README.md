# Sample Market Website

This project is a simple front-end market website demo built with HTML, CSS, and JavaScript. It showcases a clean online storefront layout with a hero section, featured products, promotional banners, and a responsive shopping interface.

## Features

- Modern landing page design
- Product showcase cards
- Mobile-friendly responsive layout
- Interactive JavaScript behavior for UI actions
- Lightweight static website setup

## Project Files

- `index.html` – page structure and content
- `style.css` – styling and layout
- `script.js` – interactive behavior and dynamic functionality

## Usage

Open `index.html` in a browser to view the website locally.

## Purpose

This project is intended as a simple sample or starter template for an e-commerce or market-style website.
